# orb-bundam

**orb-bundam** — главный репозиторий проекта OFFGRID: экосистема сфер услуг вокруг ядра `bhendho`.
Имя — от прагерманского *bundą «связка» (пие. *bʰendʰ- «связывать»): ядро связывает, проект — связка.

Код здесь не живёт. Здесь — цели, план, статус, решения между репозиториями и сборка всей системы из подрепозиториев.

## Подрепозитории

Список — [repos.yaml](repos.yaml). Рабочие клоны лежат в `repos/` (не в Git):

| Репозиторий | Роль | Состояние |
|---|---|---|
| [bhendho](https://github.com/vlad78831457/bhendho) | ядро: Go, контракты, SDK | создаётся |
| r-aaa-core-a | платформа v0.1.0: ядро + четыре модуля | источник для bhendho |
| taleweaver-app-vr-ab | продукт Taleweaver | источник улучшений ядра |

## Как читать

| Файл | Что там |
|---|---|
| [STATUS.md](STATUS.md) | одна страница: что сделано, что в работе, что ждёт решения |
| [GOALS.md](GOALS.md) | цели G-001…: зачем, когда готово, ветки |
| [ROADMAP.md](ROADMAP.md) | этапы проекта |
| [decisions/](decisions/) | решения между репозиториями (P-001…) |
| [think/](think/) | рассуждения уровня проекта |

## Команды

```
make sync     # клонировать или обновить repos/ по repos.yaml
make status   # ветка, отставание и незакоммиченное в каждом подрепозитории
make test     # проверка этого репозитория (Docker)
```

Ветки — `task/`, `think/`, `try/` с индексом `aa`, `ab`…; последовательность одна на `orb-bundam` и все его подрепозитории.
