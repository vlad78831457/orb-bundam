# orb-bundam

**orb-bundam** — главный репозиторий проекта OFFGRID: ядро `bhendho` и экосистемы сфер услуг вокруг него.
Имя — от прагерманского *bundą «связка» (пие. *bʰendʰ- «связывать»): ядро связывает, проект — связка.

Код здесь не живёт. Здесь:
- цели, план, статус;
- решения между репозиториями;
- **мануал** — подробная карта системы для тех, кто её не знает.

## Мануал

[man/](man/README.md) — устройство системы со схемами: что где лежит в коде, какие компоненты, как идут процессы.

## Подрепозитории

Список — [repos.yaml](repos.yaml). Рабочие клоны лежат в `repos/` (не в Git), `make sync`.

| Репозиторий | Роль | Состояние |
|---|---|---|
| [bhendho](https://github.com/vlad78831457/bhendho) | ядро: Go, контракты, SDK Python и TypeScript, панель админа, заготовка подразделения | открытый, строгий; выпуск `v0.3.1` |
| r-aaa-core-a | платформа v0.1.0 | источник, перенесён в `bhendho`; дальше архив |
| taleweaver-app-vr-ac | снимок системы сказок для друга, Россия (Робокасса) | снимок `orb-tale-*` |
| taleweaver-app-vr-ad | снимок системы сказок для друга, зарубежный контур (Stripe) | снимок `orb-tale-*` |

**Экосистема сказок** — отдельный проект [orb-tale-eco](https://github.com/vlad78831457/orb-tale-eco) с
подразделениями `orb-tale-servo`, `orb-tale-pay-robo`, `orb-tale-pay-stripe`. Здесь их клоны — только для
мануала (`status: ref`).

## Команды

```
make sync     # клонировать или обновить repos/ по repos.yaml
make status   # ветка, отставание и незакоммиченное в каждом подрепозитории
make test     # файлы, ссылки, пути кода в мануале, секреты, mermaid-схемы (Docker)
```

Ветки — `task/`, `think/`, `try/` с индексом `aa`, `ab`…; последовательность одна на `orb-bundam` и все его подрепозитории.
