# Глоссарий

Слова системы. Рядом — имя в коде и где об этом подробно.

## Люди и доступ

| Слово | В коде | Что это | Подробно |
|---|---|---|---|
| пользователь | `users` | человек с email (или внешним входом), кошельком, фактами и задачами | [03-data](03-data.md) |
| роль | `users.role` | `user`, `tester` или `admin`; меняется только на сервере командой `core user-role` | [13-security](13-security.md) |
| метка источника | `users.source` | `utm`-метки, с которыми человек пришёл; ставится один раз | [03-data](03-data.md) |
| токен входа | `access_token`, `refresh_tokens` | короткий токен для API и длинный для продления | [13-security](13-security.md) |

## Деньги

| Слово | В коде | Что это | Подробно |
|---|---|---|---|
| GC | `currencies`, `default_currency` | внутренняя валюта; всё в ядре считается в ней | [04-money](04-money.md) |
| кошелёк | `wallets` | у пользователя и у подразделения: `balance` и `reserved` | [04-money](04-money.md) |
| доступно | `available` | баланс минус резерв | [04-money](04-money.md) |
| резерв | `reserve`, `system_tasks.reserved` | цена бланка, отложенная при создании задачи | [04-money](04-money.md) |
| списание | `charge` | плата по факту из резерва | [04-money](04-money.md) |
| минус | `overcharge`, `overdraft_factor` | списание сверх резерва, до 1,5 резерва; баланс может уйти ниже нуля | [04-money](04-money.md) |
| возврат остатка | `release` | неизрасходованная часть резерва | [04-money](04-money.md) |
| доход подразделения | `income` | всё списанное — в кошелёк подразделения одной записью | [04-money](04-money.md) |
| проводка | `transactions` | одна запись журнала денег; журнал только дописывается | [04-money](04-money.md) |
| единица учёта | `worker_accounting` | в чём прораб считает работу: `tokens`, `images`, `tts_seconds`… | [04-money](04-money.md) |
| курс | `rate_gc`, `rate_to_base`, `rates_fixed` | сколько GC стоит единица; фиксируется в задаче при создании | [04-money](04-money.md) |
| тариф | `tariff_changes`, `tariffs` | правка цены бланка, курса или множителя минуса из панели | [04-money](04-money.md) |

## Данные и работа

| Слово | В коде | Что это | Подробно |
|---|---|---|---|
| бланк | `form`, `forms` | форма с полями: **бланк факта** (данные) или **бланк задачи** (работа за деньги) | [09-passport-and-blanks](09-passport-and-blanks.md) |
| правила полей | `fields_rules` | типы и ограничения полей бланка; ядро проверяет по ним каждое значение | [09-passport-and-blanks](09-passport-and-blanks.md) |
| ссылка на факт | `fact_ref` | поле бланка, которое указывает на опубликованный факт нужного вида | [09-passport-and-blanks](09-passport-and-blanks.md) |
| факт | `facts` | данные пользователя: герой, сказка… | [05-facts](05-facts.md) |
| версия факта | `fact_versions` | каждое изменение — новая версия: черновик, опубликована, в архиве, удалена | [05-facts](05-facts.md) |
| «кому» | `audience` | факт пользователю (`user`) или в память подразделения (любое другое слово) | [05-facts](05-facts.md) |
| память подразделения | `service_facts` | факты, которые прораб сохраняет для себя; пользователь их не видит | [05-facts](05-facts.md) |
| задача | `system_tasks` | одна работа: бланк, значения, резерв, статус, отчёт | [06-tasks](06-tasks.md) |
| снимок | `materialized` | что прораб получает вместе с задачей: значения и раскрытые ссылки на факты | [06-tasks](06-tasks.md) |
| группа | `group_id` | задачи, которые идут строго по очереди (продолжения одной сказки) | [06-tasks](06-tasks.md) |
| ключ идемпотентности | `idempotency_key` | повтор того же запроса не создаёт вторую задачу | [06-tasks](06-tasks.md) |
| вердикт | `verdict` | итог: `SUCCESS`, `WORKER_ERROR`, `DATA_REJECTED`, `LIMIT_EXHAUSTED`… | [06-tasks](06-tasks.md) |
| попытка | `attempts` | сколько раз задачу брали; после `CORE_MAX_ATTEMPTS` — отказ | [06-tasks](06-tasks.md) |
| факт-результат | `result`, `result_spec` | результат задачи, ставший фактом или его новой версией | [05-facts](05-facts.md) |

## Подразделения

| Слово | В коде | Что это | Подробно |
|---|---|---|---|
| подразделение | `services` | сфера услуг со своими бланками и прорабами: `taleweaver` | [07-gateway](07-gateway.md) |
| паспорт | `module.yaml` | описание подразделения: бланки, учёт, разметка | [09-passport-and-blanks](09-passport-and-blanks.md) |
| прораб | `service_accounts`, `prorab` | исполнитель подразделения: программа, которая берёт задачи | [07-gateway](07-gateway.md) |
| воркер | `worker/` | программа прораба целиком: прораб + конвейер + провайдеры | [tale/04-worker-map](../tale/04-worker-map.md) |
| ключ подразделения | `dk_…`, `department_keys` | выдаёт админ; по нему прораб подключается | [07-gateway](07-gateway.md) |
| шлюз прорабов | `/gateway/v1/…` | адреса для прорабов: подключиться, взять, сдать | [07-gateway](07-gateway.md) |
| уровень прораба | `TIER` | `mock`, `dumb`, `middle`, `smart` — решает подразделение | [tale/07-providers](../tale/07-providers.md) |
| приоритет | `prorab_priorities` | какой прораб берёт какой бланк; `0` — не берёт | [07-gateway](07-gateway.md) |
| разметка | `views` | как фронт рисует факты подразделения: card, section, menu | [10-front](10-front.md) |
| провайдер | `providers/*` | код прораба, который зовёт внешний API модели | [tale/07-providers](../tale/07-providers.md) |
