# az — план мануала: подробная карта системы для тех, кто её не знает

Директор, 2026-10-17: мануал по `orb-bundam` и `orb-tale-*` — подробное устройство системы со схемами и
процессами, карта аналитика. Результат — `orb-bundam/man/bhendho` и `orb-bundam/man/tale`, формат md + mermaid.
Заодно обновить сам `orb-bundam`. Сначала план, потом мануал.

## Для кого и как

- **Читатель** — аналитик, новый разработчик, друг-продавец. Код не читал, Go и Python не знает.
- **Каждая глава** начинается с ответа «зачем это» в двух-трёх строках. Затем схема, затем слова, затем «где в
  коде», чтобы проверить.
- **Схемы** — mermaid. GitHub рисует их прямо в файле:
  - `flowchart` — устройство;
  - `sequenceDiagram` — процессы;
  - `stateDiagram` — жизненные циклы;
  - `erDiagram` — данные.
- **Только проверенное.** Каждое утверждение берётся из кода, контрактов или ADR. Ссылка — путь в репозитории.
  Версии зафиксированы: ядро `v0.3.0`, `orb-tale-*` — `main` на день написания.
- **Язык** — русский, термины едины по глоссарию. Имя в коде даётся рядом в скобках: «бланк (`form`)».
